# Seguridad

Reporta las vulnerabilidades mediante un aviso de seguridad privado de GitHub en este
repositorio. Incluye una descripción reproducible y el impacto, pero no adjuntes
claves de API, comprobantes, números de cuenta ni datos de clientes.

No uses los issues públicos para vulnerabilidades sin corregir. Las claves de API entran sólo
por `VERIKO_API_KEY`; si una clave aparece en registros o en un reporte, revócala
antes de compartir cualquier evidencia.
